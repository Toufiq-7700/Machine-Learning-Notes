# 🤖 Machine Learning Notes

A collection of my machine learning learning notes, algorithm implementations, and revision materials.

## 📌 Purpose

This repository is used to:
- 📖 Document my machine learning learning journey.
- 🧠 Keep concise notes for quick revision.
- 💻 Store algorithm implementations and practice notebooks.
- 📊 Understand the intuition and mathematics behind ML algorithms.
- 🚀 Track my progress as I explore new topics.

## 📁 Repository Structure

The algorithms and notes are categorized professionally into the following folders:

- **`Supervised_Learning/`**: Linear Regression, Support Vector Machines (SVM), and K-Nearest Neighbors (KNN).
- **`Unsupervised_Learning/`**: K-Means, DBSCAN, Hierarchical Clustering, HDBSCAN, Fuzzy C-Means, and Self-Organizing Maps (SOM).
- **`Ensemble_Learning/`**: Random Forest (Classifier & Regressor), AdaBoost, CatBoost, and XGBoost.
- **`Neural_Networks_and_Deep_Learning/`**: Multi-Layer Perceptron (MLP), Recurrent Neural Networks (RNN), General Regression Neural Networks (GRNN), and LLMs.
- **`Probabilistic_and_Other_Models/`**: Hidden Markov Models (HMM) and Semi-Supervised Learning.
- **`Reports_and_Docs/`**: Detailed and condensed LaTeX project reports and supplementary overview documents.
